# Dinesh S — UI/UX Designer Portfolio

A world-class, premium portfolio website built for **Dinesh S**, Creative UI/UX Designer & Product Designer based in Chennai, India.

---

## 🚀 Live Instant Preview (No Setup Required!)
You can view the portfolio immediately in any web browser without running commands:
- Simply double-click **`portfolio.html`** in this folder, or right-click and choose **"Open with Chrome / Edge"**.
- Everything is fully interactive:
  - 🎨 Interactive Constellation Canvas background with cursor interaction
  - ✍️ Live role typing animation
  - 💼 In-depth Case Study modals (Digital Marketer App, E-Commerce Checkout, Accent Techno Soft Internship)
  - 📄 Dedicated **Printable / PDF-Ready Resume Modal**
  - 🛠️ Filterable skills and infinite tools marquee
  - 📱 Validated contact form and one-click copy buttons for phone and email

---

## 💻 Tech Stack (React + Vite + TypeScript)
The codebase also includes a complete production-grade React 18 application:
- **Framework:** React 18, Vite 6, TypeScript
- **Styling:** Tailwind CSS 3, Custom CSS Variables, Glassmorphism
- **Animations:** Framer Motion, Canvas Particle Physics
- **Icons:** Lucide React, React Icons (`SiFigma`, `SiAdobexd`, `SiGoogle`, `SiCoursera`, etc.)

### Running with Node.js & Vite (Optional):
```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build production bundle
npm run build
```

## 📁 Project Architecture
```
protfolio/
├── portfolio.html              # Standalone zero-dependency instant browser edition
├── index.html                  # Vite SPA entry point with complete SEO & Schema.org
├── styles.css                  # Dark theme tokens (#0B1120, #3B82F6, #06B6D4), glassmorphism
├── package.json                # React 18, Vite 6, Tailwind, Framer Motion
├── tsconfig.json               # TypeScript ES2020 bundler configuration
├── vite.config.ts              # Vite config with React plugin and alias
├── tailwind.config.js          # Custom theme colors, keyframes, and glows
├── public/
│   └── favicon.svg             # Gradient "D" SVG favicon
└── src/
    ├── main.tsx                # React DOM entry
    ├── App.tsx                 # Root layout with interactive ResumeModal
    ├── index.css               # Tailwind directives and utility classes
    ├── lib/
    │   └── animations.ts       # Reusable Framer Motion variants
    └── components/
        ├── Navbar.tsx          # Sticky blur header with active spy & resume trigger
        ├── Hero.tsx            # Animated greeting, typing effect, floating badges, CTAs
        ├── About.tsx           # Bio, B.Sc CS background, core strengths, quick facts
        ├── Skills.tsx          # Categorized tabs, progress bars, tool logos
        ├── Projects.tsx        # Case study cards with deep-dive modal
        ├── Experience.tsx      # Accent Techno Soft internship details & learning journey
        ├── Certifications.tsx  # Google UX, UI/UX Specialization, Figma credentials
        ├── Timeline.tsx        # Vertical milestone timeline (Muthayammal College, Accent)
        ├── Achievements.tsx    # Statistical metrics (+35% completion, 1,000+ views)
        ├── ToolsMarquee.tsx    # Infinite looping tool badges
        ├── Contact.tsx         # Copy email/phone, social links, validated form
        ├── ResumeModal.tsx     # Printable / downloadable full formatted resume
        ├── SectionWrapper.tsx  # Viewport scroll triggers
        └── Footer.tsx          # Back to top, copyright, links
```
